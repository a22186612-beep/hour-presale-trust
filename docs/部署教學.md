# 時數預售信託：從頭部署教學（Remix + MetaMask）

準備：MetaMask 切到 Sepolia 網路，5 個帳號（老六、Dragon、Phoenix、乾爹、乾媽）都要有一點 Sepolia ETH。先把這 3 個地址複製到記事本：**老六、Dragon、Phoenix**（MetaMask 點帳號名稱可複製）。

## 一、建檔
1. 左邊 File Explorer 點「Create」旁的新增檔案圖示，建立 `HourToken.sol`，把專案資料夾 `contracts/HourToken.sol` 的內容整份貼上。
2. 再建 `HourTrust.sol`，貼上 `contracts/HourTrust.sol` 的內容。
3. 不用建 MockUSDC.sol，tUSDC 沿用舊的。

## 二、編譯
1. 左邊點 Compile 圖示。
2. Compiler 選 `0.8.34`。
3. 展開 Advanced Configurations，勾 **Enable optimization**，數字 `200`。
4. 分別點開 `HourToken.sol`、`HourTrust.sol`，各按一次藍色 Compile。兩個都要出現綠勾。（第一次會自動下載 OpenZeppelin，要等幾秒。）

## 三、連錢包
1. 左邊點 Deploy 圖示。
2. Environment 選 `Browser Extension`（舊版叫 Injected Provider - MetaMask）。
3. MetaMask 切到**老六**的帳號，Remix 的 Account 欄應該顯示老六的地址。之後 4 個合約都用老六部署。

## 四、部署兩個 HourToken
Contract 選 `HourToken`，展開 Deploy 旁的參數欄位，**全部用英文半形，字串不用加引號（Remix 會處理；若報錯再加雙引號）**：

| 參數 | Dragon 這份 | Phoenix 這份 |
| --- | --- | --- |
| name_ | Dragon Hour | Phoenix Hour |
| symbol_ | dHOUR | pHOUR |
| agency_ | 老六地址 | 老六地址 |
| consultant_ | Dragon 地址 | Phoenix 地址 |
| consultantName_ | Dragon | Phoenix |
| monthLength_ | 480 | 480 |

按 Deploy → MetaMask 按確認。成功後下方 Deployed Contracts 會出現，點旁邊的複製圖示取得地址。**依序做 Dragon、Phoenix，兩個地址分別記下來。**

## 五、部署兩個 HourTrust
Contract 改選 `HourTrust`：

| 參數 | Dragon 這份 | Phoenix 這份 |
| --- | --- | --- |
| hour_ | Dragon 的 HourToken 地址 | Phoenix 的 HourToken 地址 |
| usdc_ | 0x0B8E8FFD77c8c14fDF185CC031d004Ec38B23566 | 同左 |
| consultantName_ | Dragon | Phoenix |
| hoursPerWeek_ | 25 | 25 |
| shopHours_ | 15 | 15 |
| totalWeeks_ | 12 | 12 |
| weeksPerMonth_ | 4 | 4 |
| hourPrice_ | 70000000 | 70000000 |
| periodLength_ | 120 | 120 |

## 六、填進前端
把 4 個合約地址填進 `frontend/index.html` 上方的 `CONFIG.consultants`（每位顧問一組 `hour` 與 `trust`），5 個帳號地址填進 `CONFIG.people`。之後到 Etherscan 驗證合約（Flatten 成單一檔案，Solidity Single file、0.8.34、optimization 200 runs），再依 README 開啟前端。

## 常見問題
- 參數欄位報錯：字串加雙引號，例如 "Dragon Hour"。
- 按 Deploy 沒反應：確認 Environment 是 Browser Extension，且 MetaMask 在 Sepolia。
- Compile 紅字：確認 Compiler 版本 0.8.34，且兩個檔案內容貼完整。
